# Theseus Project - BMK-Studio Modified Version

This is a modified version of the original Theseus Project, based on the Microsoft dashboard for the original Xbox.

The goal of this version is to add new visual features, extra customization options, background music, panels, and new dashboard interactions while keeping the original Xbox dashboard feeling.

---

## Features

### 1. BMK Controller Panel

- Background Mesh
- Orbs
- Skins
- Visibility
- UIX Settings / Config

---

### 2. Custom Orbs

- Main Orb
- Setting Main Orb
- Emulator Orb
- Application Orb
- Game Orb
- Dashboard Orb

---

### 3. skin.ini Support

- Custom background images
- Background image rotation
- Background image timer
- Custom SMAP
- SMAP rotation
- SMAP timer
- CellWall visibility

---

### 4. REZN8 Menu

- Integrated REZN8 quick menu
- Switch between M$Dash and REZN8
- Access to main dashboard sections

---

### 5. BMK ScreenSaver

- Custom BMK ScreenSaver added

---

### 6. Background Music

- Automatic background music
- Random music mode
- Play / Pause support
- Soundtrack switching
- Song switching

---

### 7. Music Panel

- Current music title display
- Scrolling music text

---

### 8. Second Music Panel

- Active soundtrack
- Current track
- Track duration
- Remaining time

---

### 9. Multi-Info Panel

- IP address
- Free space E / F / G
- BIOS info
- Dashboard version
- Temperature info
- Fan speed

---

### 10. BMK Menu Animation

- Custom menu animation
- Pods animation
- Panels animation
- Animation mode: Off / UIX / BMK

---

### 11. MemoryX MiniGame

- MemoryX mini-game integrated into the dashboard

---

### 12. Visibility Options

- Show / hide dashboard elements
- Manage dashboard visual elements from BMK Controller Panel

---

## Controls

```text
A  =>  Select

B  =>  Back

X  =>  NextClockInfoPanel
White(Tab)+(X)  =>  MemoryX (MiniGame)

Y  =>  Play/Pause BackGroundMusic

LeftThumbDown (W)  =>  BMKControlerPanel

RightThumbDown (C)  =>  Toggle beetween MusicPanel

White (Tab)  =>  Superkey

Black

LeftDown (A)  =>  Screensaver_tHc
LeftDown White(Tab)+(A)  =>  Screensaver_BMK

RightDown (E)  =>  Toggle Beetween M$Dash and Rezn8

Up  =>  MenuUp
White(Tab)+(Up)  =>  BMKNextBackground Or BMKNextSmap

Down  =>  MenuDown
White(Tab)+(Down)  =>  BMKPreviousBackground Or BMKPreviousSmap

Right => Next SoundTrack
White(Tab)+(Right)  =>  Next Song

Left => Previous SoundTrack
White(Tab)+(Left)  =>  Previous Song
```
